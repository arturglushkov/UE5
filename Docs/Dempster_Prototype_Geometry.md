# Dempster — геометрия прототипа (кухня + столовая), этап Phase 1

Сгенерировано скриптом `Scripts/Geometry/build_dempster_prototype.py` (Blender как Python-модуль, `pip install bpy`) по чертежам ID 09.30.2026: D1.00 (план), D1.01 (потолки), D2.01 (план кухни/столовой), D2.02 (развёртки 01–03). Всё, чего нет на чертежах, принято «на вскидку» и перечислено в разделе 3 — проверьте и поправьте значения в начале скрипта, он пересобирает всё за ~20 секунд.

Интерактив, который получает `placement.json`: 16 распашных дверей (`HingedDoor`, угол 105°/115° холодильники/90° дверь в коридор), 8 ящиков (`Drawer`, ход = глубина − 2), 1 подъёмный фасад AVENTOS (`FlapUp`, T02), 1 откидная дверца посудомойки (`FlapDown`, 88°) с двумя лотками, которые `requires` открытую дверцу, 12 LED-полос (`Light`), 2 выключателя (`Switch` → `LightGroup.Kitchen` / `LightGroup.Dining`), 109 статики. Три объекта помечены как конфигурируемые поверхности: столешница острова (`Configurable.Countertop.Kitchen`, слот `STONE`), деревянные панели фасадной стены (`Configurable.WallPanel.Dining`, слот `PANEL`), каменная полоса (`Configurable.FeatureStone.Dining`, слот `STONE_BLUE`).

Соглашения соблюдены: pivot дверей на оси петли на плоскости фасада, локальный +X — из шкафа, Z вверх, L-петля = дверь уходит в +Y; ящики — pivot сзади-снизу-по центру, ход +X; откидные — на верхнем (lift) / нижнем (drop) ребре. Масштаб 1,0 везде, негативных масштабов нет. UV — box-проекция, 1 UV = 1 м. Фаски: 0.5 мм каркас/рамки, 1 мм фасады, 2 мм камень, 3 мм стены (модификатор Bevel применяется при экспорте).

Материальные слоты называются по роли (`FRONT`, `CARCASS`, `INTERIOR`, `STONE`, `STONE_BLUE`, `PANEL`, `WOOD`, `MIRROR_BRONZE`, `GLASS_BRONZE`, `GLASS`, `METAL_BRONZE`, `METAL_BLACK`, `STAINLESS`, `PAINT`, `CEILING`, `FLOOR`, `LED`, `FABRIC`, `APPLIANCE`, `CONCRETE`) — скрипт материалов следующего этапа назначит `MI_*` по этим именам.

## 2. Как завести в UE (Mac, 5.8) — один скрипт

1. Собрать `NOAREditor` в Xcode (см. README), открыть проект.
2. **Tools → Execute Python Script** → `Scripts/Editor/noar_bootstrap_prototype.py` (или в Output Log: `py "<repo>/Scripts/Editor/noar_bootstrap_prototype.py"`).
3. Открыть `/Game/Apartments/DEMPSTER/Maps/L_DEM_Prototype`, Play.

Что делает бутстрап (каждый шаг идемпотентен, можно перезапускать после перегенерации геометрии):

| Шаг | Скрипт | Результат |
| --- | --- | --- |
| 1 | `noar_import_fbx.py` | 3 FBX → `/Game/Apartments/DEMPSTER/{Architecture,Millwork,Furniture}`, Nanite, pivot сохранён, коллизия только у архитектуры |
| 2 | `noar_setup_materials.py` | `M_Master_Opaque/Glass/Mirror/Emissive` (параметры Tint/Roughness/Metallic/UseTextures/Tiling/T_*), `MI_<ROLE>` для 21 слота, библиотека отделок из `finish_options.csv` (17 MI-заглушек с тонами спецификации), назначение на все меши по имени слота |
| 3 | `noar_setup_level.py` | `DA_LightPreset_Day/Evening/Night` (солнце, экспозиция, состояния групп света), `DA_Room_KIT/DIN`, `DT_FinishOptions_DEMPSTER`, `DA_Apartment_DEMPSTER`; Blueprint-подклассы `BP_NOAR_GameMode/PlayerController/Character`, `BP_Interactive*`, `BP_InteractiveLight_*` (с компонентом света), `BP_LightSwitch`, `BP_DayNightManager`, `BPV_CameraZone`; уровень `L_DEM_Prototype` с солнцем, SkyLight (real-time), атмосферой, туманом, PostProcess (Lumen, экспозиция EV 6–12), PlayerStart в столовой, DayNightManager, GameMode override |
| 4 | `noar_setup_input.py` | `IA_*` и `IMC_Walk/UI/Photo` (WASD/стрелки/мышь/геймпад, E/ЛКМ — взаимодействие, V — камера, F/R/L/P/I — панели), подключены в class defaults BP |
| 5 | `noar_millwork_assembler.py` | расстановка 149 объектов по `placement.json`, интерактив с параметрами и зависимостями, конфигурируемые поверхности |
| 6 | `noar_spawn_lights.py` | 25 источников по `lights.json` |

Если какой-то шаг пишет warning «cannot set …» — это переименованное свойство API 5.8, пришлите строку, поправлю. Руками остаётся только то, что из Python не делается: добавить пакет **Third Person** и назначить Manny + ABP в `BP_NOAR_Character` (Mesh → Skeletal Mesh / Anim Class), иначе персонаж ходит невидимой капсулой. UI (панели отделок, комнат, света, меню, карточка продукта, подсказки) собран в C++ и появляется сам — `WBP_*` не нужны.

Проверка на месте (Gate 1): старт в столовой лицом к острову; выключатель у проёма гасит столовую, выключатель у двери — кухню; дверца посудомойки блокирует лотки, пока закрыта; дверь в коридор открывается внутрь коридора (−X) и блокирует проход, пока закрыта; L — смена Day/Evening/Night.

## 4. Известные упрощения прототипа (не ошибки, а следующий шаг)

- Ручки — бронзовые планки-заглушки 16 см; профиль Gola / реальные HW с ведомости — на этапе материалов.
- Стулья, люстра, смеситель — массовые заглушки для масштаба и освещения; заменяются на Datasmith/производителя (`Data/Dempster/products.csv`).
- Техника (холодильник/морозильник за фасадами, духовка в башне) — только фасады.
- Дверь в коридор ставится в плоскости стены; коробка статична.
- Штора — две сплошные «ширмы» у краёв остекления; складки — на этапе материалов (tileable displacement).

## 5. Вся квартира (оболочка по D1.00), 22.10.2026

- `Scripts/Geometry/extract_plan.py` читает векторный план D1.00 (PDF): контуры стен (линии 0.84/1.26 pt), проёмы → перемычки над дверями, подписи комнат. Масштаб 1/4" = 1'-0" (1 pt = 1,693 см), начало координат то же, что у прототипа. Результат — `Data/Dempster/plan_dempster.json`.
- Вручную обведены (их нет в чертеже чистыми линиями): внешний контур квартиры, остекление (7 участков), контур балкона.
- `noar_plan_shell.py` строит из этого: пол и потолок (290 см) по контуру, стены всех комнат, перемычки над дверями (229 / 244 см), остекление в пол, «кожу» по контуру за всеми непрозрачными участками, балкон со стеклянным ограждением.
- Исправлено по плану: стена столовой с панелями была отзеркалена (развёртка D2.02-01 смотрит на юг) — теперь: возврат 2'-11" у остекления, панели над W.I.C., проём в холл 3'-7½", высокие шкафы 5'-9" у входной двери D.01 (глубина 30 см). Дверь D.01 — в юго-западном углу кухни, 36"×96".
- В остальных комнатах пока только оболочка и потолочные светильники; двери открытые проёмы. Мебель и millwork спален, санузлов, гардеробной, кабинета — следующий этап (D2.05–D2.13).
